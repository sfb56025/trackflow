# Trackflow

Application web de gestion de finances personnelles containerisée (PHP / MariaDB / Docker).

## 🚀 Installation et lancement

1. Dupliquer le fichier d'exemple pour configurer les variables d'environnement :
   \`\`\`bash
   cp .env.example .env
   \`\`\`

2. Lancer les conteneurs Docker :
   \`\`\`bash
   docker compose up -d --build
   \`\`\`

3. Accéder à l'application :
   - **URL** : http://localhost:8080
